AllCraft Launcher

Developer: Fallingink
Project Type: Personal Minecraft Launcher
Platform: Windows 10 / Windows 11
Project Status: Private Development
Commercial Status: Non-commercial

About

AllCraft Launcher is a personal Windows desktop application developed to provide a convenient and integrated way to manage Minecraft installations.

The project is developed independently for personal Minecraft gameplay and software development purposes.

Project Goals

The goal of AllCraft Launcher is to simplify Minecraft game management by bringing essential features together in one desktop application.

The project includes the following areas:

- Minecraft game version management
- Minecraft installation and download management
- Mod loader support, including Forge, Fabric and NeoForge
- Mod discovery and download
- Minecraft game instance management
- Mod compatibility checking
- Independent game directory management

Mod Platform Integration

AllCraft Launcher integrates with Modrinth and plans to integrate with the official CurseForge API.

The intended CurseForge API functionality includes:

- Searching for Minecraft mods
- Retrieving mod project information and metadata
- Filtering mod files by Minecraft version
- Filtering by mod loader
- Viewing file information and dependencies
- Downloading compatible mod files into the selected local Minecraft instance

All API usage will comply with the applicable platform terms, API restrictions and distribution permissions.

Mod Distribution Policy

AllCraft Launcher does not operate an independent mod hosting service.

The project does not intend to mirror, re-upload, modify or independently redistribute mod files through third-party servers.

Mod discovery and downloads will use authorized platform-provided resources. Mod authors' permissions and attribution will be respected.

Commercial Status

AllCraft Launcher is strictly a personal, non-commercial project.

There are no plans to generate revenue through advertisements, subscriptions, donations, sponsorships or other commercial activities.

The launcher is not intended for public distribution or commercial operation.

Source Code and Privacy

The launcher source code is private and is not publicly distributed.

This repository is intended only to provide general project information and documentation. It does not contain the launcher's source code, API credentials or private user data.
